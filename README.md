# Mathematical Models in Biotechnology

This repository contains the manuscript and reproducible examples for the
chapter *Mathematical Models in Biotechnology* by Jeffrey D. Varner, prepared
for *Comprehensive Biotechnology*, 4th edition. The chapter derives the
intracellular flux balance, explains how biological information enters reaction
bounds, and develops worked examples based on a urea-cycle network and a
feedback-regulated pathway.

## Repository layout

```text
chapter/
  Chapter.tex                 Main LaTeX document
  References.bib              Bibliography
  sections/                   Chapter sections
  figures/                    Figures used by the manuscript
  Makefile                    PDF build recipe
code/
  Project.toml                Julia dependencies
  Manifest.toml               Exact resolved dependency versions
  Include.jl                  Shared project setup
  fba/                        Urea-cycle model, uncertainty analysis, and tests
  feedback/                   Dual-feedback model, comparison, sweep, and tests
  data/                       Inputs, current outputs, and legacy CSV tables
  figs/                       Generated plots and a committed pathway schematic
```

## Computational environment

The committed manifest was generated with Julia 1.12.6. From the repository
root, install the recorded dependency versions with:

```bash
julia --project=code -e 'using Pkg; Pkg.instantiate()'
```

The environment includes JuMP and HiGHS for linear programming, BSTModelKit for
the kinetic reference model, CairoMakie for figures, and CSV/DataFrames for
tabular output.

## Reproducing the worked examples

Run these commands from the repository root:

```bash
julia --project=code code/fba/urea_cycle_uq.jl
julia --project=code code/feedback/run_feedback.jl
```

The urea-cycle script performs the nominal calculation and the 10,000-draw
Monte Carlo analyses. It writes summary tables and complete draw logs to
`code/data/`, including solver status, active bounds, and urea export for each
draw. It also writes `urea_fba.pdf` and `urea_saturation.pdf` to `code/figs/`.

The feedback script integrates the kinetic reference model, evaluates the FBA
bound configurations, and performs the activity-factor parameter sweep. It
writes `feedback_fba.csv` and `feedback_sweep.csv` to `code/data/`, and
`feedback_ledger.pdf` and `feedback_robustness.pdf` to `code/figs/`.

The simpler nominal urea-cycle calculation can be run separately with:

```bash
julia --project=code code/fba/run_fba.jl
```

This command writes `urea_fba_solution.csv` to `code/data/` and
`urea_fba.pdf` to `code/figs/`.

The remaining manuscript diagrams are committed under `chapter/figures/`.
TikZ sources are included for `lp_geometry.pdf`, `active_subset.pdf`, and
`feedback_network.pdf`. The file `urea_network.pdf` is committed as the final
schematic and is not regenerated by the Julia workflow.

## Tests

Run both example test suites from the repository root:

```bash
julia --project=code code/fba/test_urea_cycle.jl
julia --project=code code/feedback/test_dual_feedback.jl
```

## Building the chapter

Copy regenerated figures into the manuscript directory, then build the PDF:

```bash
cp code/figs/*.pdf chapter/figures/
make -C chapter
```

The build requires a recent LaTeX distribution with `pdflatex` and BibTeX. The
result is written to `chapter/Chapter.pdf`. The Makefile tracks the manuscript
figure PDFs, so copying a regenerated figure triggers a rebuild.

## Data provenance

`code/data/park_saturation.csv` contains the substrate-concentration and
Michaelis-constant records used in the urea-cycle saturation calculation. Its
header records the source and the treatment of the missing forward substrate
for reaction `v2`. The extraction script is
`code/fba/extract_park_saturation.py`; the source spreadsheet is not committed.

`code/data/urea_thermodynamics.csv` records the five eQuilibrator reaction
queries used by the urea-cycle model, including the KEGG compound identifiers,
standard transformed reaction Gibbs energies, displayed 95% confidence
intervals, transformed-state conditions, heuristic direction assignments,
source URLs, and access date. These values were queried at pH 7.5, pMg 3.0,
ionic strength 0.25 M, and 298.15 K. The separate Monte Carlo value
`DG_SIGMA = 2.0` kJ/mol is an illustrative standard deviation and is not the
eQuilibrator confidence interval. All other CSV files used by the current
worked examples are either model inputs or outputs regenerated by the commands
above.

The files `cho_trajectories.csv`, `cybernetic_diauxie.csv`,
`lstm_metrics.csv`, and `s4_metrics.csv` are retained legacy outputs from
earlier exploratory examples. They are not inputs to the current worked
examples or manuscript figures.

`code/data/urea_turnover_numbers.csv` records the provenance assessment for the
five nominal turnover numbers used by the urea-cycle model. The assessment used
BRENDA release 2026.1, downloaded on July 22, 2026 as
`brenda_2026_1.json.tar.gz` (SHA-256
`bb2549d02b7255de2272b35701c331493caad16b82eb38a41adb2e03bbb0d2e1`). The
raw CC BY 4.0 database download remains in the ignored `data/` directory. Exact
BRENDA matches support the nominal values for `v2` through `v5`, including the
1.08 s^-1 L-arginine turnover number selected for rat nitric oxide synthase.
The EC 6.3.4.5 entry for `v1` has no turnover-number field, so `v1` uses the
approximately 10 s^-1 median reported by Bar-Even et al. for 1,942 unique
enzyme--natural-substrate reactions (2011; DOI `10.1021/bi2002289`) as a
documented global default. The
CSV reports the organisms, substrates, conditions, literature identifiers,
exact match counts, and selection rules needed to interpret the retained
values.
